# Проверка официального API AUTO.RIA

Документация проверена 7 сентября 2026 года. Начальная точка — [официальная страница разработчиков](https://developers.ria.com/docs/), которая ссылается на документацию на `docs-developers.ria.com`.

## Реализованные методы

- [Поиск объявлений](https://docs-developers.ria.com/en/used-cars/auto_search_and_info/search_auto): `GET https://developers.ria.com/auto/search`. Параметры: `api_key`, `category_id`, `marka_id[0]`, `model_id[0]`, `page`, `countpage`. Индекс страницы начинается с 0. Идентификаторы находятся в `result.search_result.ids`, количество — в `result.search_result.count`. Прочие фильтры передаются только из `AUTORIA_SEARCH_PARAMS`.
- [Карточка объявления](https://docs-developers.ria.com/en/used-cars/auto_search_and_info/auto_info): `GET https://developers.ria.com/auto/info?api_key=…&auto_id=…`. Используется объект ответа из текущего официального примера, а не старые неофициальные обёртки-массивы.
- [Статистика по периодам](https://docs-developers.ria.com/en/used-cars/average_price/statistic_average_price): `POST https://developers.ria.com/auto/statistic-avarage-price/`. Написание `avarage` соответствует документации. Query: `user_id`, `api_key`; JSON: `langId`, `period`, `params.omniId`. Это платный метод. Отдельный `AutoRiaStatisticsService` готов отправлять документированный запрос, но автоматически не вызывается и не подменяет локальную медиану. Сервис возвращает ответ без интерпретации графиков и распределений.

## Сопоставление полей карточки

| Поле приложения | Поле ответа |
| --- | --- |
| external_id | autoData.autoId |
| title, brand, model | title, markName, modelName |
| generation, year | autoData.generationName, autoData.year |
| price_usd | USD |
| mileage_km | autoData.raceInt × 1000 |
| city, region | locationCityName, stateData.regionName |
| fuel_type, engine_volume | autoData.fuelName: вид топлива и число перед `л` |
| transmission, drive_type | autoData.gearboxName, autoData.driveName |
| description | autoData.description |
| seller_type | dealer.type, если есть; иначе неизвестен |
| vin | VIN, только полный незамаскированный VIN |
| url | linkToView, относительно https://auto.ria.com |
| фото | photoData.seoLinkB |
| активность | autoData.active, isSold, fromArchive |

Пробег `raceInt=140` означает 140 000 км. Пропущенный пробег не превращается в ноль. Отсутствующая цена USD или несовместимая структура отменяет импорт с понятным сообщением. Номер телефона, SVG VIN и зашифрованный VIN не обрабатываются. Публичный VIN может отсутствовать по выбору продавца.

`photoData.all` содержит идентификаторы, а не готовые URL; адреса остальных фото не выдумываются. Пока сохраняется главное фото. Галерея приложения поддерживает произвольный список фотографий провайдера; количество в оценке — реально загруженные URL, поэтому для AUTO.RIA полнота фото консервативно занижается. Полную галерею можно подключить отдельным документированным методом после проверки доступа аккаунта и бюджета запросов.

## Квота и полнота

[Официальные лимиты](https://docs-developers.ria.com/en/main_rules/AUTO) на дату проверки: бесплатный пакет — 30 запросов в час, 1 000 в месяц. По умолчанию один проход требует до 21 запроса (поиск + 20 карточек), раз в 24 часа: около 630 запросов за 30 дней без повторов. Лимиты общие для ключа; учитывайте другие приложения. Первая загрузка при старте тоже расходует квоту. HTTP 429 немедленно останавливает импорт; временные сетевые ошибки/5xx допускают не более трёх попыток запроса. Между запросами есть пауза. Повторный запуск реального импорта запрещён до истечения настроенного интервала, но не менее часа; время последней попытки хранится в БД.

Число страниц ограничено. Если `count` больше количества уникальных полученных ID, проход считается неполным. Старые объявления не снимаются по отсутствию в неполном ответе. При полном обходе помечаются только давно не виденные записи **этого источника и набора поисковых параметров**. Изменение параметров не снимает объявления из предыдущей выборки. Реальный `active=false`, `isSold=true` или `fromArchive=true` снимает конкретную запись сразу. При неуспешном импорте изменения откатываются целиком.

## Что ещё нужно для проверки на реальном аккаунте

В `.env` нужен ваш `AUTORIA_API_KEY` и `LISTING_PROVIDER=autoria`. Для обычного поиска `user_id` не требуется. При доступе по ключу можно проверить реальные ответы и ограничения вашего пакета. Если структура отличается, достаточно обезличенного JSON ответа без ключа, телефонов и VIN. В текущем окружении ключ отсутствовал: выполнены контрактные тесты на документированной структуре, живой запрос с ключом не выполнялся.
