# Как пользоваться ПЕРЕКУП

## Для чего это приложение

Приложение помогает выбрать объявления, которые стоит изучить внимательнее: сравнивает цену с похожими машинами, вычитает ваши расходы и показывает признаки риска. Оно не подтверждает состояние машины, юридическую чистоту или гарантированную прибыль.

В работающем приложении эта справка доступна в разделе **«Как пользоваться»**: http://localhost:8000/guide. Инструкция публикации кода: [GITHUB.md](GITHUB.md).

## Первый просмотр

1. Откройте главную страницу. В правом верхнем углу указан источник: тестовые данные либо AUTO.RIA.
2. В Mock-режиме нажмите «Обновить объявления», если выборка ещё не появилась. Ключ не нужен.
3. Начните с кнопки «Потенциально выгодные»: она выбирает скидку от 10%, положительную прибыль после расходов и риск до 40/100, сортируя по прибыли.
4. Кнопка «Низкий риск» оставляет риск до 25. «До 12 000 $» задаёт бюджет. Быстрые кнопки заменяют текущий набор фильтров; после них можно добавить свои условия.
5. Слева доступны поиск по названию, марка, модель, год, цена, пробег, место, топливо, коробка и условия сделки. После выбора марки в списке остаются её модели.
6. Нажмите «Показать автомобили». Применённые фильтры видны над результатами; крестик убирает один фильтр. «Сбросить» очищает форму.
7. Выберите сортировку по баллу, потенциальной прибыли, цене или времени первого наблюдения. Страницы переключаются внизу каталога.

Поиск по названию работает с текстом карточки: например, `Golf` или `Camry`. Он не переводит названия и не исправляет опечатки. Фильтры применяются к локальной базе. Они не отправляют новые поисковые запросы в AUTO.RIA.

## Что означают показатели

| Показатель | Значение |
| --- | --- |
| Активные | Активные объявления текущего источника в локальной базе |
| Новые за сутки | Впервые замечены приложением в последние 24 часа, не обязательно только что опубликованы |
| Потенциально выгодные | Скидка ≥10%, прибыль >0, риск ≤40 при сохранённых расходах |
| Последнее обновление | Время последнего успешного импорта; не время обновления всей площадки |
| Цена продавца | Цена в USD, которую передал источник |
| Оценка рынка | Медиана подходящих активных аналогов после очистки |
| Процент ниже рынка | Разница между оценкой и ценой продавца относительно оценки |
| Потенциальная прибыль | Оценка рынка минус цена, ремонт и другие расходы |
| Риск | Эвристическая шкала 0–100, где больше означает больше поводов для проверки |
| Балл | Приоритет просмотра 0–100; не вероятность удачной покупки |
| Аналоги | Число использованных похожих предложений, не число проданных автомобилей |
| Фото | Количество URL фотографий, сохранённых в базе |

## Карточка автомобиля

Нажмите название или фотографию. Откроются характеристики, доступные снимки, описание, история цены, аналоги, калькулятор и объяснение оценки.

- **Фотографии:** миниатюра переключает основной снимок. Демо-фото показывают нужную модель, но не конкретную вымышленную машину.
- **Описание:** читайте полностью. Стоп-фразы не заменяют контекст.
- **История:** показывает цены со времени первого импорта. При одном наблюдении графика изменения ещё нет. После изменений появляется диаграмма последних 12 наблюдений; таблица сохраняет полную историю.
- **Аналоги:** можно открыть каждую использованную машину и проверить, насколько она похожа.
- **Объяснение:** показывает вклад скидки, доходности, количества аналогов, пробега, свежести, условной ликвидности и рисков.
- **Оригинал:** доступен у реального объявления. У Mock-карточки внешнего объявления нет.

## Как посчитать прибыль

Допустим:

```text
Оценка рынка               13 000 $
Цена продавца              10 000 $
Предполагаемый ремонт          700 $
Другие расходы                400 $
Потенциальная прибыль        1 900 $
```

Укажите ремонт в первом поле. Во втором соберите дополнительные расходы: поездку/доставку, диагностику, оформление и другие ожидаемые затраты. Приложение не определяет эти суммы автоматически.

При вводе появляется **предпросмотр**. Чтобы сохранить расходы и обновить балл, нажмите «Пересчитать и сохранить». Введённые суммы сохраняются для этой машины после следующих импортов. Смена настроек расходов в `.env` не заменяет уже сохранённые ручные значения.

Этот пример показывает арифметику. Автомобиль может продаться дешевле, ремонт оказаться дороже, а продажа занять больше времени.

## Откуда берётся рыночная цена

Сначала подбираются объявления того же источника, марки и модели; сама машина исключается. Учитываются поколение при наличии, год ±2, тип топлива, коробка, близкий двигатель и пробег. Сначала используется региональная подборка, а при её недостатке — общая.

Объявления с существенными стоп-фразами исключаются из аналогов. Затем удаляются явные ценовые выбросы. Нужен минимум аналогов — по умолчанию пять после очистки. Если данных недостаточно, цена рынка, прибыль и итоговый балл не рассчитываются.

Подробная формула и коэффициенты находятся в [README](../README.md#как-работает-оценка); реализация — в `app/services/scoring.py`.

## Почему фотографии раньше были одинаковыми

В первой версии все Mock-карточки ссылались на один файл BMW. Теперь используются семь фотографий пяти соответствующих моделей. Golf и Octavia имеют по два ракурса, остальные — по одному. Внутри одного модельного ряда фото могут повторяться, поскольку 41 учебное объявление не является 41 настоящим автомобилем.

После обновления исходников выполните импорт — он заменит URL фото в уже сохранённых объявлениях. Демо-снимки сохраняются локально и не требуют ключа API или интернета при каждом просмотре. [Авторство и лицензии](PHOTO_CREDITS.md) доступны также в приложении.

При подключении AUTO.RIA используются только URL из API этой карточки; тестовые фото туда не подставляются. Пока импортируется главное фото. Отсутствующий снимок отображается как отсутствующий, а не заменяется другой машиной.

## Как проверить историю цены в демо

```bash
docker compose exec app python -m scripts.seed --with-history
```

Команда импортирует вариант с четырьмя сниженными ценами, затем базовые цены. У этих машин появится изменение в истории. Даты — реальные времена тестовых импортов. Обычный импорт без изменения цены не добавляет лишних записей.

## Как переключиться на реальные объявления

Получите ключ на официальном портале AUTO.RIA, укажите `LISTING_PROVIDER=autoria` и `AUTORIA_API_KEY` в `.env`, настройте `AUTORIA_SEARCH_PARAMS`, затем пересоздайте приложение:

```bash
docker compose up -d --force-recreate app
```

Mock и AUTO.RIA показываются отдельно и не смешиваются в оценках. Настройки, лимиты и проверенная документация: [AUTORIA.md](AUTORIA.md). Никому не отправляйте настоящий ключ в скриншотах, сообщениях об ошибках и GitHub issue.

## Ограничения, которые важно понимать

- Это отбор для дальнейшей проверки, не автоматическое решение о покупке.
- «Низкий риск» означает мало найденных сигналов в доступных данных, а не отсутствие реальных проблем.
- Ликвидность оценивается по объёму похожих предложений, а не статистике сроков продажи.
- Время первого наблюдения может отличаться от даты публикации продавцом.
- При частичном импорте отсутствие машины в ответе не снимает её автоматически. Площадка могла просто не вернуть её на первой странице.
- Для редких моделей, маленькой выборки или пропущенных характеристик оценка будет недоступна.
- Ручной и автоматический импорт не выполняются одновременно. Во время импорта сохранение нового расчёта может попросить подождать.
